# AWS High Availability WordPress Project

## Services Used

- EC2
- IAM
- RDS
- ELB
- Route 53
- ACM
- S3

## Project Architecture

Users
→ Route53
→ Load Balancer
→ EC2 WordPress
→ RDS Database

Backup Flow

Production EC2
→ S3
→ DR EC2
